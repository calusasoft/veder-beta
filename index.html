Veder

Network Scanner — Version 0.9.0 Beta

Veder is a lightweight, portable IPv4 network scanner designed for computer technicians and IT professionals. It helps discover devices on local and remote networks using ICMP, ARP, and optional TCP discovery.

Results include IP addresses, hostnames, MAC addresses (where available), response times, and discovery methods.

Beta download

The beta release is being finalized. Download instructions will be available here for selected testers.

System requirements

Designed for 64-bit Windows 10, Windows 11, and Windows Server 2016 or newer with a graphical desktop environment. Compatibility testing is ongoing.

Veder requires no installation or administrator elevation for normal operation. It runs as a single, self-contained executable.

Beta testing

This limited beta is intended for invited testers. Please use Veder only on networks you are authorized to examine. Do not redistribute the beta without permission.

The executable is currently unsigned. Windows security software may display a warning. Follow your normal security policies.
